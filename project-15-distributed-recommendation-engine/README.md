# Project 15 – Distributed Recommendation Engine

Enterprise Recommendation Platform using Apache Spark MLlib for personalized recommendations, customer behavior analysis, and product affinity modeling.

---

# Overview

This project demonstrates large-scale recommendation systems used by modern enterprises.

The platform provides:

- Personalized Recommendations
- Collaborative Filtering
- Content-Based Recommendations
- Hybrid Recommendation Models
- Customer Personalization
- Product Affinity Analysis
- Recommendation Analytics
- Enterprise AI Insights
