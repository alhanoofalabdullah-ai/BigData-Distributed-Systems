# Installation Guide

## Navigate to Project

```bash
cd project-18-distributed-machine-learning-pipeline
```

## Install Dependencies

```bash
pip install pyspark pandas scikit-learn
```

## Run Feature Engineering

```bash
python feature-engineering/feature_builder.py
```

## Run Training

```bash
python training/train_model.py
```

## Open Spark UI

```text
http://localhost:8080
```
