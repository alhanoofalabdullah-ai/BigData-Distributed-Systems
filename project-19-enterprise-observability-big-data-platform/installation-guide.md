# Installation Guide

## Navigate to Project

```bash
cd project-19-enterprise-observability-big-data-platform
```

## Start Platform

```bash
docker-compose up -d
```

## Open Grafana

```text
http://localhost:3000
```

## Open Prometheus

```text
http://localhost:9090
```

## Open Jaeger

```text
http://localhost:16686
```
